# 10 — PEAK Feature Inventory (ไล่ทุกเมนูจากหน้าเว็บจริง)

แหล่งข้อมูล: หน้าจอ PEAK v2.199.0 (แพ็กเกจ PRO Plus) — 9 พ.ย. 2569
วัตถุประสงค์: รายการฟีเจอร์/หน้าจอ/ตั้งค่าทั้งระบบ เพื่อใช้เป็นต้นแบบระบบเรา ตั้งแต่เปิดกิจการจนปิดงบ (แดชบอร์ดออกแบบเองได้)

สัญลักษณ์คอลัมน์ **ขอบเขต**: 🧾 = บัญชี/ภาษี (ผม), 🧩 = ส่วนอื่น (คุณ), 🔌 = API/การเชื่อมต่อ (เน้นพิเศษตามที่สั่ง)

## 0. สรุป 10 บรรทัด
1. PEAK มี 9 เมนูหลัก (หน้าหลัก, รายรับ, รายจ่าย, ผู้ติดต่อ, สินค้า, การเงิน, บัญชี, คลังเอกสาร, ตั้งค่า) + รวมรายงาน 40 รายงาน + ตั้งค่า 33 หน้า
2. **การเชื่อมต่อภายนอกมี 3 ชั้น**: (a) Partner marketplace 33 แอป (e-commerce, OMS, WMS, CRM, HR, payment, bank feed), (b) Open API + Webhook, (c) AI assistant — ดู §8
3. e-Tax Invoice ผ่าน 3 provider (Google time-stamp, INET, Leceipt) ส่ง XML+PDF ลายเซ็นอิเล็กทรอนิกส์ แนบกลับเอกสารอัตโนมัติ
4. ระบบเลขที่เอกสาร 24 ชุด (รายรับ 13, รายจ่าย 11) ตั้ง prefix/ปี/เดือน/วัน/running ได้ + แยกชุดใบกำกับภาษี + เลือก "ใช้เลขที่ void ซ้ำ" ได้
5. สิทธิ์ผู้ใช้ 8 role มาตรฐาน + custom role (PRO Plus 2 / PREMIUM ไม่จำกัด), เพิ่ม PEAK Support, ล็อกงวด, ล็อกเอกสารรายใบ
6. บัญชี: สมุดรายวัน 5 เล่ม + สถานะ 6 ขั้น (ร่าง/รอตรวจสอบ/รออนุมัติ/ควรพิจารณา/อนุมัติ/ยกเลิก), GL mapping ของ CN/DBN ไม่อ้างอิง และ IR/GR clearing ตั้งค่าได้ (212305 เป็นค่า default ไม่ใช่ hard-code)
7. สินค้า: perpetual inventory, FIFO auto-COGS, คลังหลายแห่ง, ใบเบิก/ส่งคืน/โอนย้าย/ปรับต้นทุน, รายการจัดชุด, SKU
8. การเงิน: เงินสด/ธนาคาร/e-Wallet/สำรองรับจ่าย, เช็ครับ/จ่าย, WHT 2 ทาง (ถูกหัก/หัก) + e-WHT + Text file ยื่น ภ.ง.ด., กระทบยอดธนาคาร, ปฏิทินเงินเข้า-ออก
9. ทุกเอกสารมี: ร่าง→อนุมัติ, สำเนา, ล็อก, void (soft), ลิงก์สาธารณะ+รหัส, ส่งอีเมล, แนบไฟล์ 10/25MB, แท็ก, กลุ่มจัดประเภท, คอมเมนต์ @mention, ประวัติ, template "รายการโปรด", AI OCR สร้างค่าใช้จ่ายจากรูป
10. แพ็กเกจกำหนดฟีเจอร์ (ดู §9) — ของเราควรเปิดทั้งหมดโดยไม่ล็อกแพ็กเกจ

### 3.2 ฟอร์มสร้างเอกสาร (field ร่วมทุกใบ)
- แถบสลับชนิดเอกสาร (QO→IV→RE→TIV, EXP, POA→PA), "รายการโปรด" (template), "ตั้งค่าการแสดงผล" (เลือกคอลัมน์)
- หัวเอกสาร: เลขที่ (auto/override), อ้างอิง 35, ลูกค้า/ผู้ขาย (ค้นหาหรือสร้างทันที), ที่อยู่, โทร, วันที่ออก, วันที่ครบกำหนด/ใช้ได้ถึง, ประเภทราคา (แยก/รวมภาษี), การออกใบกำกับภาษี (ออก/ไม่ออก)
- รายการ: สินค้า/บริการ หรือ บัญชี, จำนวน, ราคา/หน่วย, ส่วนลด/หน่วย, ภาษี (7%/0%/ยกเว้น), มูลค่าก่อนภาษี, **หัก ณ ที่จ่ายต่อบรรทัด** (ไม่มี/0.75/1/1.5/2/3/5/10/15/กำหนดเอง), คำอธิบายรายการ 1,000, 50 บรรทัด/หน้า, เพิ่มต้นทุนอื่น (PA/POA)
- สรุป: ส่วนลดรวม, มูลค่าคำนวณภาษี, VAT, จำนวนเงินทั้งสิ้น
- ชำระ/รับชำระ: โหมดพื้นฐาน/ขั้นสูง, หลายงวด (ครั้งที่ N), วันที่, ช่องทาง, จำนวน, หมายเหตุ 20, WHT, "ยังไม่ชำระ (ตั้งหนี้ไว้ก่อน)"
- ท้าย: หมายเหตุสำหรับลูกค้า/ผู้ขาย 1,000, แนบไฟล์ ≤10 ไฟล์/25MB (pdf,png,jpg,gif,txt,csv,xlsx,docx,pptx,zip,rar,7z,key,rdx,heic,heif), แท็ก, กลุ่มจัดประเภท
- ปุ่ม: ยกเลิก / บันทึกร่าง / อนุมัติ
- EXP: "สร้างเอกสารจากไฟล์อัตโนมัติด้วย AI" (OCR รูป/PDF ≤25MB), เลขที่ใบกำกับภาษี 35
- JV: สมุดบัญชี, วันที่, เลขที่, อ้างอิง, ผู้ติดต่อ, คำอธิบาย 512, บรรทัด (เลขที่บัญชี*, บัญชีย่อย, คำอธิบาย*, Dr*, Cr*), รวม Dr=Cr

### 3.3 หน้ารายละเอียดเอกสาร
- แท็บ: ข้อมูลเอกสาร / ข้อมูลการชำระ / ข้อมูลการหักเงินมัดจำ / ข้อมูลประวัติ (audit)
- สถานะ badge + ลิงก์ไปสมุดรายวัน (RV-202611006) + พิมพ์บันทึกบัญชี
- ส่งเอกสาร: อีเมล / คัดลอกลิงก์สาธารณะ / คัดลอกรายละเอียดเอกสาร
- พิมพ์ (PDF)
- ตัวเลือก: แก้ไข / คัดลอก / ล็อกเอกสาร / สร้างใบลดหนี้ / สร้างใบวางบิล / ยกเลิกเอกสาร
- ความคิดเห็น + @mention (แจ้งเตือนหมวด ระบบ/กล่าวถึง/ภายนอก/ดาวน์โหลด)

### 3.4 หน้า list
สร้าง, พิมพ์รายงาน, แท็บสถานะพร้อมจำนวน, "เอกสารอัตโนมัติ" (recurring), ช่วงวันที่ออก, ค้นหา + ค้นหาขั้นสูง, คอลัมน์ เลขที่/คู่ค้า/วันที่/กำหนด/มูลค่าสุทธิ/VAT/สถานะ, แถวผลรวม, page size
