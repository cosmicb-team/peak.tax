# 07 — ผังบัญชี 3 ชั้น: อะไรล็อก อะไรแก้ได้ และ mapping สำหรับ plug ระบบอื่น

## 1. โครง 3 ชั้น

```
ชั้นที่ 1  หมวดใหญ่ 5 หมวด            ← ล็อก (สมการบัญชี / TFRS for NPAEs)
           1 สินทรัพย์ Dr · 2 หนี้สิน Cr · 3 ทุน Cr · 4 รายได้ Cr · 5 ค่าใช้จ่าย Dr
                 ▲ derive อัตโนมัติจากชั้นที่ 2 (trigger) ผู้ใช้ไม่ต้องเลือก
ชั้นที่ 2  รายการย่อในงบการเงิน 38 รายการ   ← ล็อก (ประกาศ DBD เรื่องรายการย่อที่ต้องมีในงบการเงิน แบบ 2 บริษัทจำกัด)
           ตาราง fs_line_item — ทุกบัญชีต้องชี้มาที่นี่ 1 รายการ
                 ▲ ผู้ใช้เลือกได้ว่าบัญชีใหม่เข้ารายการไหน
ชั้นที่ 3  บัญชีรายตัว (code + ชื่อ)         ← แก้ได้อิสระ ต่อ org
           เริ่มจาก template PEAK 264 บัญชี → เพิ่ม/เปลี่ยนชื่อ/จัดต้นไม้/ปิดใช้งาน
```

ไฟล์: `data/fs-line-items.{csv,json}`, `data/chart-of-accounts-mapped.{csv,json}`, seed SQL `db/seed/001_fs_line_items.sql`, `db/seed/002_account_template_peak.sql`

## 3. Attribute ต่อบัญชี (ตาราง `account`)

| Field | ล็อก? | ความหมาย |
|---|---|---|
| `fs_line_item` | ผู้ใช้เลือกจาก 38 ค่า | ชั้นที่ 2 |
| `category`, `is_current` | **auto จาก trigger** | ชั้นที่ 1 |
| `normal_balance` | auto เว้นแต่ `is_contra` | ด้านที่ยอดเพิ่ม |
| `is_contra` | ผู้ใช้ตั้งได้ | ค่าเผื่อหนี้สงสัยจะสูญ, ค่าเสื่อมสะสม, รับคืน, ส่วนลด, เงินปันผล |
| `tax_kind` + `tax_form` | ล็อกถ้า `is_system` | บอก Tax Engine ว่าบัญชีนี้คือภาษีตัวไหน ยื่นแบบอะไร (36 บัญชีใน template) |
| `cit_deductible` | ผู้ใช้ตั้งได้ (เฉพาะหมวด 5) | `full` / `limited` (รับรอง, บริจาค, หนี้สูญ) / `none` (เบี้ยปรับ, ภาษีเงินได้) → ใช้ทำรายการบวกกลับ ภ.ง.ด.50 |
| `is_system` | ระบบตั้ง | บัญชีที่ posting engine ใช้โดยตรง — ห้ามย้าย fs/เปลี่ยน tax_kind (ลูกหนี้, เจ้าหนี้, ภาษีทุกตัว, มัดจำ, สินค้า, รายได้หลัก, กำไรสะสม, พัก) |
| `template_code` | ระบบตั้ง | ชี้กลับ PEAK code ต้นทาง; NULL = org เพิ่มเอง |
| `ext_codes` jsonb | ผู้ใช้ตั้ง | `{"express":"...","flowaccount":"..."}` รหัสบัญชีของระบบเดิม ใช้ตอนนำเข้าข้อมูล |
| `parent_code`, `level`, `allow_posting` | ผู้ใช้ตั้ง | จัดต้นไม้/บัญชีกลุ่ม (header ไม่รับ posting) |

กฎใน DB (trigger):
1. เปลี่ยน `fs_line_item` → `category`/`is_current` คำนวณใหม่เสมอ
2. บัญชี `is_system` เปลี่ยน fs หรือ tax_kind ไม่ได้ → `SYSTEM_ACCOUNT_LOCKED`
3. บัญชีที่มี journal แล้ว ย้ายข้ามงบ (BS ↔ PL) ไม่ได้ → `ACCOUNT_HAS_POSTINGS` (ย้ายภายในงบเดียวกันได้ แต่ต้องเปิดเผยในหมายเหตุ)
4. `seed_chart_of_accounts(org_id)` คัดลอก template 264 บัญชีให้ org ใหม่

## 5. Plug กับระบบอื่น

**ขาเข้า (import ผังจากระบบอื่น)**: นำเข้า CSV `code, name, ext_system_code` → ผู้ใช้ map แต่ละบัญชีไปยัง `fs_line_item` (38 ตัวเลือก) + ติ๊ก contra/tax_kind ถ้ามี → ระบบตรวจว่าทุก tax_kind ที่ posting engine ต้องใช้ (vat_output, vat_input, wht_payable PND3/53, wht_receivable, AR 113101-equivalent, AP) มีอย่างน้อย 1 บัญชี ไม่ครบ = ไม่ให้เปิดใช้

**ขาออก (export ให้นักบัญชี / สรรพากร)**:
- งบการเงิน DBD (e-Filing XBRL): roll up ตาม `fs_line_item` ตรงกับ taxonomy รายการย่อ
- ภ.ง.ด.50: ใช้ `cit_deductible` ทำรายการบวกกลับ + `fs_line_item` PL-01..08 กรอกช่องรายได้/ค่าใช้จ่าย
- ภ.พ.30 / ภ.ง.ด.3/53: ดึงจาก `tax_kind` ไม่ใช่เลขบัญชี
